## 2024-11-20 - Ensure Keyboard Accessibility on Interactive Custom Components
**Learning:** When using standard non-interactive elements (like `<Icon>`, `<CopyIcon>`, `<HStack>`, or regular HTML elements such as `<div>`, `<span>`) as interactive buttons by adding an `onClick` handler, they remain inaccessible to keyboard users because they cannot be focused and do not listen to standard keyboard trigger events (like the "Enter" or "Space" key).
**Action:** Always add `role="button"`, `tabIndex={0}`, an appropriate `aria-label`, and an `onKeyDown` handler to custom interactive elements. The `onKeyDown` handler should check for `e.key === "Enter" || e.key === " "` and execute the same action as `onClick`. Ensure you call `e.preventDefault()` inside the `onKeyDown` handler, specifically for the Space key, to prevent the default behavior of scrolling the page.
